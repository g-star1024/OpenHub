# OpenHub Windows

OpenHub Windows is the Tauri edition of OpenHub for Windows 10 and Windows 11.

This project is intentionally separated from the native macOS SwiftUI app:

- macOS source: `Sources/GitHubAppHub`
- Windows source: `windows/openhub-tauri`

## Requirements

- Windows 10 or Windows 11
- Node.js 20+
- Rust stable
- Microsoft Visual Studio Build Tools with the C++ workload
- WebView2 Runtime

## Development

```powershell
cd windows/openhub-tauri
npm install
npm run dev
```

## Build Installer

```powershell
cd windows/openhub-tauri
npm install
npm run build:windows
```

Build outputs are generated by Tauri under:

```text
windows/openhub-tauri/src-tauri/target/release/bundle/
```

## Notes

- The Windows version shares the same product behavior: GitHub discovery, category browsing, search, favorites, language switching, and GitHub Star sync through a personal token.
- The current Windows client stores settings in browser local storage inside the Tauri WebView. A future iteration should migrate the token to a Tauri secure storage plugin.
