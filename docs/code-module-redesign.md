# OpenHub 代码模块布局与同步逻辑优化方案

## 目标

- 让代码模块更接近 macOS 开发工具的工作台感，而不是普通表单拼接。
- 降低顶部按钮和底部提交区的视觉重量。
- 让用户一眼知道：当前文件是否保存、Git 是否有改动、是否有本地提交未推送、下一步应该点什么。
- 继续保持同步逻辑简单：优先复用本机 Git 凭据，只有认证失败时才使用 OAuth token 兜底。

## 布局更新

### 1. 顶部编辑器工具栏

现状：

- “Git 状态 / 保存 / 同步全部到 GitHub”按钮偏大，集中在右上角，视觉上抢编辑器主体。

调整：

- 文件名左侧保持主标题，分支 `main` 使用浅蓝胶囊标签。
- 文件名右侧增加状态胶囊，例如“有 2 个本地提交未推送”。
- 右上角按钮改为：
  - `刷新状态`
  - `保存文件`
  - `同步到 GitHub`
- 主按钮只保留一个：`同步到 GitHub`，使用蓝色强调。
- 文案从“同步全部到 GitHub”改短，避免按钮过长。

### 2. 底部 Git 工作区

现状：

- 状态、Diff、提交三张卡片信息割裂。
- 提交区域过重，按钮文案较长。
- 顶部进度和状态散落，失败时不够明确。

调整：

- 底部头部固定为：
  - `Git 工作区`
  - 当前分支状态：`main ahead 2`
  - 同步结果摘要：`上次同步：刚刚失败，远端未更新`
  - 右侧状态标签：`文件已保存`、`有本地提交未推送`
- 下方三列继续保留，但更紧凑：
  - `变更`：显示变更数量和文件列表。
  - `Diff 预览`：显示选中文件或整体 diff 摘要。
  - `提交与同步`：提交信息输入框 + 单一主按钮。

### 3. 提交面板

调整：

- 标题改为 `提交与同步`。
- 输入框默认文案保持 `Update from OpenHub`。
- 主按钮改为 `提交并同步`。
- 面板底部展示流程提示：`保存文件 → git add → commit → push`。

## 同步逻辑更新

### 1. 状态读取

- 进入代码模块时读取：
  - 当前分支。
  - `git status --short`。
  - `git status --branch --porcelain=v2` 或等价命令，解析 ahead / behind。
  - 最近一次同步结果。
- UI 状态拆分：
  - `工作区干净`
  - `有未保存文件`
  - `有未提交变更`
  - `有本地提交未推送`
  - `远端有更新`
  - `同步失败`

### 2. 保存逻辑

- `保存文件` 只保存当前打开文件。
- 保存后不自动 commit / push。
- 保存完成后立即刷新 Git 状态。

### 3. 同步逻辑

点击 `提交并同步` 或顶部 `同步到 GitHub` 后：

1. 自动保存当前打开文件。
2. 清理 stale `.git/index.lock`。
3. 检查当前目录必须是 Git 仓库。
4. 检查 `origin` 是否存在。
5. 解析当前分支和 ahead / behind。
6. 执行 `git add .`。
7. 如果有 staged changes，执行 `git commit -m <message>`。
8. 如果没有 staged changes 但存在 ahead，直接 push。
9. 优先执行原生 `git push`，复用本机 GitHub Desktop / 终端凭据。
10. 如果 non-fast-forward，提示用户先拉取或执行一次 `pull --rebase --autostash` 后重试。
11. 如果认证失败，再尝试 OAuth token URL 兜底。
12. 完成后刷新 Git 状态，并明确提示：
    - `同步完成`
    - `本地提交已创建，但推送失败`
    - `远端有更新，需要处理后再同步`

### 4. 错误提示

- `github.com:443` 连接失败：提示网络或代理问题，并说明本地提交是否已经创建。
- `remote: Not Found`：提示检查 origin 地址和 Git 凭据。
- `index.lock`：自动清理后重试一次；仍失败再提示。
- `not a git repository`：提示重新选择本地仓库路径。

## Windows 同步

- Windows/Tauri 版本同步同一套文案和布局概念。
- Windows 端先复用 Web 前端结构，按钮文案与 macOS 保持一致：
  - `刷新状态`
  - `保存文件`
  - `同步到 GitHub`
  - `提交并同步`
